# 书屿隐私说明

收藏、阅读进度、批注及缓存默认保存在本机。应用已关闭 Android 系统自动备份（`allowBackup="false"`），并在系统备份与设备迁移规则中排除本地书库、离线缓存与凭据，请使用应用内备份功能导出数据（可按需勾选阅读时长统计、阅读留白纪念、净化规则与段落修订、应用外观设置）。

联网行为仅在对应功能启用或触发时发生：在线书库访问文库接口与插图源；在线听书将待朗读文本发送给 Microsoft Edge 在线语音服务或你自行配置的自定义 HTTP TTS 接口；云端书源与同步连接你配置的 WebDAV / S3 服务；远程导入净化规则、在线字体下载及检查更新会分别访问目标链接、Google Fonts / GitHub 字体源与 GitHub Releases；Wi-Fi 传书仅在局域网开启临时服务并需 PIN 验证。

在线服务可能看到网络请求、连接信息及发送给其处理的内容；敏感文本请仅使用本地阅读与离线系统语音。自动更新检查可在关于页面关闭，下载安装均需手动确认；本地文件夹通过你授予的 SAF 目录权限访问。问题反馈请勿附带账号凭据、私密正文或未经脱敏的日志。
